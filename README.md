# Adaptive Multimodal Orchestration Eval

Prototype and experiments for "Adaptive Multimodal Agentic Orchestration with
Confidence-Aware Fusion and Dynamic Task Replanning for Enterprise
Automation" (working title), targeting IEEE Access.

Companion paper source lives in the `adaptive-multimodal-orchestration/`
module of the `ai-spm-guardrail-paper` repo.

Status: early development. Architecture, datasets, and baselines are being
built incrementally (confidence-aware fusion and a basic planner first),
not all at once — see commit history / branch for current state.
